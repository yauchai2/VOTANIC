Alan (2026-10-09): XRCC should feel like Discord but not boring; aesthetic, fun, graphic. Research (/mnt/project-files/research/20261009-xrcc-discord-feel-research.html) concluded: borrow place-feel (stable rail/content/status), honest presence dots, project identity, one human voice; do NOT borrow chat/channels, notification noise, gamification, public presence.

Integrated guideline: /mnt/project-files/design-system/20261009-xrcc-studio-feel-guideline.md (8 principles P1–P8, pattern catalogue, copy voice). Playbook §10 points to it. Concept frames in Workbench UI page (Launcher 239:1035, Quick switcher 240:1052, Connections 247:1113, Packages empty 247:1396); voice strings in /mnt/project-files/xrcc-studio-feel/20261009-voice-pass-launcher.md.

**Why:** product should feel alive and illustrated, still professional for schools/enterprise.
**How to apply:** presence/status stays honest (only Accepted/Saved locally/Queued/Delivered/Failed; never infer abandoned/failed/passed, D-16/D-22/D-27). Playfulness at edges (empty states, first success); plain in destructive/data dialogs. Existing tokens only. See [[ui-quality-human-not-generic-ai]], [[ui-copy-english-first]], [[integrate-research-into-memory-not-screens]].

**Illustrations (Alan, 2026-10-09):** illustrations may be freely designed as long as the look and feel aligns with XRCC; decorative, no token binding needed, no new Library tokens, status colours not used as decoration.

**Rollout (Alan, 2026-10-09):** do NOT change the current old XRCC UI for now; it will be updated gradually and made more fun over time. Studio feel is a guideline for future/new work, and concept frames stay concepts.
