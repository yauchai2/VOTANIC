Alan (2026-10-14): outside real application UI (anything that affects what a user does while working), text layout can be bolder and more creative, e.g. bigger size contrast. He found the Workbench Debug Panel Tooltip list and the Library Typography list boring (uniform small tables, weak hierarchy).

**Why:** Discord (studied via Mobbin) has two voices: shouty display type on marketing/onboarding, quiet small type in the product. Contrast comes from one very large size against small muted text.
**How to apply:** Docs, lists, concept screens, empty states, headers: eyebrow (caption UPPER subtle) + heading/xl title, hero numerals at heading/xl, section headers heading/lg, groups as caption eyebrows, at least 2.7:1 biggest to smallest. Real product UI: no big type. Existing text styles and variables only; styles top out at heading/xl 32, display/2xl 48 and display/3xl 64 are only suggested, never add.
