Alan (2026-11-05): "不要跟AIProviderPanel.mp4的UI/UX, 這是developer的測試。UI/UX需要重製成更好".

**Why:** the prototype panel (Providers, Task models, Voice presets, Sessions stacked like a form) was built by developers to test the architecture; it is not a design.
**How to apply:** Use the prototype only for functions and data (which tasks, providers, preset fields). Rethink structure, hierarchy and interaction from the user's goal (e.g. task-first, visual cards), not the prototype's order or controls.
