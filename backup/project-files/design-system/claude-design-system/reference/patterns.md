Interaction notes (from the team's UI rules, apply when relevant, not as law): Confirm enabled only when data changed. Delete asks for confirmation and states the consequence. Icon-only buttons have tooltips. Lists show default, hover, selected, disabled, and hover reveals extra buttons. Disabled controls say what unlocks them. Expand arrows: collapsed ▶, expanded ▼. Search starts on Search or Enter.

Studio feel (new work): places not pages, small honest presence, projects with a face, one voice, delight at the edges only (empty states, first success), honest status over fun status. No chat model, no XP or streaks, no public presence.
