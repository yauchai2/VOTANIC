## 1. Overview
PC 上用快捷鍵或按鈕打開「Remote Control」彈窗,顯示目前專案的 QR 碼與連接位址,讓其他裝置連接並控制該專案。

## 2. Experience context
- 每個專案一個 QR,無 lobby(Confirmed,D-JD-02)。
- 新功能,不沿用舊 Remote Trigger(Confirmed,D-JD-03)。
- Remote Control server 內嵌於 Launcher;XR 使用者在 Launcher 開 QR(Confirmed,D-JD-04)。PC 版由快捷鍵或按鈕開啟,server 只在遊玩模式運行(Confirmed,D-JD-05)。
- Open:D-JD-06 Windows 防火牆 UX、D-JD-07 HMD 連接、D-JD-09 Remote Control UI 由誰設計。

## 3. Behaviour spec
| # | 元素 | 行為 | 標籤 |
|---|---|---|---|
| 1 | 標題列 + 關閉 | 關閉只隱藏彈窗,遊玩模式進行時 server 繼續運行 | Assumption |
| 2 | 狀態標籤 | Active(綠點)/ 未運行(灰點)/ 被擋(琥珀點);反映遊玩模式與 server 狀態 | Assumption |
| 3 | QR 碼 | 編碼本專案連接位址;未運行或被擋時淡化並以浮層說明 | Confirmed(按專案)+ Assumption(呈現) |
| 4 | 連接位址 | 唯讀文字框 + 複製按鈕;server 未運行時兩者停用 | Assumption |
| 5 | 底部行動 | 每個狀態只有一個 Primary:複製位址 / 開始遊玩模式 / 重試 | Assumption |

## 4. Design decisions
- 只用 XRCC Theme / System 變數與 Library 元件(Button Primary/Secondary、Text Input),字型樣式由 PC UI 檔匯入;全 Dark mode。
- 控件高度跟 Library(Large 48 / Medium 36 / Small 28):地址欄 Input 與 Copy 按鈕同為 Medium 36;底部按鈕為 Large(Library 發佈新高度後更新)。Notion 舊指引寫 40,已過時。
- 狀態標籤為自訂 frame(Library 的 Tag variants 不適用);警告色用已發佈的 `status/warning/*`。
- QR 圖樣為佔位,不可掃描。

## 5. Edge cases(未畫,待決定)
- 複製成功後的 toast(文案見下表)。
- 位址過長(超長專案名或 IP 格式):文字框截斷並可選取複製。
- 防火牆被擋時是否提供「開啟 Windows 防火牆設定」入口(Open:D-JD-06)。
- 多網卡電腦的位址選擇。
- Standard / Premium 是否有差異:Notion 未提及。

- 版本:XRCC 4.2。Figma 檔名按慣例 `YYYYMMDD_<version> <function>`。
- 不變部分:Library 內所有 component、token、text style 皆未被修改。
