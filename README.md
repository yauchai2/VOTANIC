## XRCC design system

All XRCC UI design, including Launcher screens and web prototypes, uses the [XRCC PC Design Library](https://www.figma.com/design/De8nKqO81yciw4wH5xfpxA/?node-id=17465-272) by default.

- Reuse applicable Library tokens for colour, typography, spacing and shape. Use Library components and variants for controls, icons and feedback wherever they fit.
- Use custom elements only for a feature-specific design that existing components and variants cannot express. Keep applicable Library tokens in those elements and record the exception in the design handoff.
- Verify the Library bindings and instances in Figma and carry the same tokens and component states into the web prototype.
